# loyalty-demo-app

แอป **สะสมแต้ม + ผู้ช่วย AI ตอบลูกค้า** สำหรับร้านเล็ก เขียนด้วย **React Native (Expo + TypeScript)** ใช้คู่กับ [loyalty-demo-backend](https://github.com/kitchu-studio/loyalty-demo-backend) (Go + PostgreSQL)

เป็นโปรเจกต์ตัวอย่างสำหรับโชว์งาน ไม่ใช่แอปที่เปิดใช้จริงของร้านใดร้านหนึ่ง

## หน้าจอ

| แท็บ | ใครเห็น | ทำอะไรได้ |
|---|---|---|
| **การ์ดแต้ม** | สมาชิก | ดูแต้มบนการ์ดแสตมป์ ดูว่าอีกกี่แต้มจะแลกรางวัลได้ กรอกโค้ดจากพนักงานเพื่อรับแต้ม ดูประวัติ |
| **ของรางวัล** | สมาชิก | แลกแต้มเป็นคูปอง ดูคูปองที่ยังไม่ใช้ (โชว์โค้ดให้พนักงาน) |
| **ถามร้าน** | สมาชิก | ถามผู้ช่วย AI เรื่องเวลาเปิด-ปิด เมนู โปรโมชัน แต้มของตัวเอง |
| **หน้าร้าน** | พนักงาน | ออกโค้ดแต้มจากยอดบิล ตรวจและยืนยันส่งมอบคูปอง แก้ข้อมูลร้านที่ AI ใช้ตอบ ดูสรุป |

พนักงานคือบัญชีที่สมัครด้วยอีเมลที่ตั้งไว้ใน `ADMIN_EMAILS` ของ backend

## เทคโนโลยี

Expo (React Native) · TypeScript แบบ strict · React Navigation (bottom tabs) · TanStack Query · Axios · expo-secure-store (เก็บ token) · ฟอนต์ IBM Plex Sans Thai

## จุดที่ตั้งใจทำ

- **เก็บ token ใน SecureStore** (Keychain / Keystore) ไม่ใช่ AsyncStorage และมี **refresh token อัตโนมัติ** เมื่อ access token หมดอายุ คำขอที่ล้มพร้อมกันหลายตัวจะรอรีเฟรชครั้งเดียว ถ้ารีเฟรชไม่ได้จะกลับไปหน้าเข้าสู่ระบบ
- **แยกสถานะข้อมูลกับหน้าจอ** ข้อมูลจากเซิร์ฟเวอร์อยู่ใน TanStack Query (แคช โหลดซ้ำ ดึงลงเพื่อรีเฟรช) หน้าจอไม่ถือสำเนาของตัวเอง
- **ข้อความ error เป็นภาษาไทย** แปลงจากข้อความของ API ในที่เดียว (`src/api/errors.ts`)
- **ผู้ช่วย AI ไม่ได้รู้ข้อมูลจากแอป** แอปส่งเฉพาะข้อความสนทนา ส่วนข้อมูลร้านและแต้มของผู้ถามเซิร์ฟเวอร์ใส่เอง จึงแก้ให้ AI เห็นแต้มคนอื่นไม่ได้
- ข้อความภาษาไทยเว้น line-height กว้างพอให้สระและวรรณยุกต์ไม่โดนตัด

## ลองรันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป และเปิด backend ไว้ก่อน (ดูวิธีใน repo backend: `docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build`)

```bash
npm install
npx expo start
```

กด `a` เพื่อเปิดบน Android emulator (Expo จะติดตั้ง Expo Go ให้เอง) หรือสแกน QR ด้วยแอป Expo Go บนมือถือ

แอปเรียก backend ที่:

| อุปกรณ์ | ที่อยู่ที่ใช้ |
|---|---|
| Android emulator | `http://10.0.2.2:8081` (ค่าเริ่มต้น) |
| iOS simulator | `http://localhost:8081` (ค่าเริ่มต้น) |
| มือถือจริง | ตั้ง `EXPO_PUBLIC_API_URL=http://<IP ของคอมในวง Wi-Fi เดียวกัน>:8081` |

```powershell
# ตัวอย่างบน Windows PowerShell
$env:EXPO_PUBLIC_API_URL="http://192.168.1.20:8081"; npx expo start
```

### ลองใช้เป็นขั้นตอน

1. สมัครบัญชีพนักงานด้วยอีเมลที่ตั้งใน `ADMIN_EMAILS` ของ backend (จะเห็นแท็บ "หน้าร้าน")
2. ไปแท็บ "หน้าร้าน" พิมพ์ยอดบิล เช่น 250 แล้วกด "ออกโค้ด" จะได้โค้ด 6 ตัว
3. ออกจากระบบ สมัครบัญชีลูกค้าอีกบัญชี แล้วกรอกโค้ดที่หน้า "การ์ดแต้ม" จะได้ 25 แต้ม
4. ไปแท็บ "ของรางวัล" แลกของ จะได้คูปอง
5. เข้าบัญชีพนักงานอีกครั้ง ตรวจโค้ดคูปองแล้วกด "ส่งมอบแล้ว"

## โครงสร้าง

```
App.tsx              ครอบ provider ทั้งหมด เลือกหน้าตามสถานะล็อกอิน
src/api              axios, refresh token, ฟังก์ชันเรียก API, แปลง error เป็นภาษาไทย
src/auth             AuthContext (ล็อกอิน สมัคร ออกจากระบบ กู้ session)
src/components       ปุ่ม ช่องกรอก การ์ดแสตมป์ ตั๋วคูปอง เส้นปรุ
src/screens          หน้าจอทั้ง 5
src/navigation       แท็บล่าง (แท็บ "หน้าร้าน" แสดงเฉพาะพนักงาน)
```

## หมายเหตุสำหรับตอนเผยแพร่

- ค่าเริ่มต้นเรียก backend ผ่าน HTTP เพื่อให้ลองในเครื่องได้ สำหรับแอปจริงให้ชี้ `EXPO_PUBLIC_API_URL` ไปที่ HTTPS เสมอ (Android รุ่นใหม่บล็อก HTTP ในแอปที่ build ขายจริง)
- ยังไม่ได้ใส่ไอคอนและ splash screen ของแอป เพิ่มได้ใน `app.json`
